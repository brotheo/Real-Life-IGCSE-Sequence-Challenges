5 Difficult Real-Life IGCSE Sequence Challenges

Multiple inputs · intermediate calculations · dependency order · debugging — no IF, FOR, WHILE, or CASE

Teacher Answer Key
Hard

1. ✈️ Flight Booking Calculator

A travel company wants a program to calculate the total cost of a flight booking.

Write Cambridge pseudocode that:

  1. Inputs the ticket price.
  2. Inputs the number of passengers.
  3. Inputs the baggage fee per passenger.
  4. Inputs the number of bags per passenger.
  5. Calculates the ticket cost.
  6. Calculates the total baggage cost.
  7. Calculates the final booking cost.
  8. Outputs the final booking cost.

Example

TicketPrice = 8500
Passengers = 3
BagFee = 1200
BagsPerPassenger = 2

Expected:

TicketCost = 25500 BaggageCost = 7200 FinalCost = 32700
Challenge question: Explain which calculations must happen before FinalCost can be calculated.

Model answer: Both TicketCost and BaggageCost must be calculated first, since FinalCost is their sum. Neither depends on the other, so they can be calculated in either order relative to each other — but both must come before FinalCost.

Answer pseudocode
INPUT TicketPrice
INPUT Passengers
INPUT BagFee
INPUT BagsPerPassenger

TicketCost ← TicketPrice * Passengers
BaggageCost ← BagFee * BagsPerPassenger * Passengers

FinalCost ← TicketCost + BaggageCost

OUTPUT FinalCost
Hard

2. 🏨 Hotel + Service Calculator

A hotel charges:

  • A room price per night
  • A breakfast price per person per day
  • A service charge calculated from the room cost

Write pseudocode that:

  1. Inputs room price per night.
  2. Inputs number of nights.
  3. Inputs number of guests.
  4. Inputs breakfast price per guest.
  5. Inputs service charge percentage.
  6. Calculates room cost.
  7. Calculates breakfast cost.
  8. Calculates service charge.
  9. Calculates final cost.
  10. Outputs all three costs and the final cost.

Example

Room = 2500
Nights = 4
Guests = 2
Breakfast = 300
ServiceCharge = 10
RoomCost = 10000 BreakfastCost = 2400 ServiceChargeAmount = 1000 FinalCost = 13400

🔍 Sequence challenge

Ask: Can the program calculate ServiceChargeAmount before calculating RoomCost? Explain why.

Model answer: No — ServiceChargeAmount is a percentage of RoomCost, so RoomCost must exist first. Calculating it earlier would use an undefined or zero value.

Answer pseudocode
INPUT Room
INPUT Nights
INPUT Guests
INPUT Breakfast
INPUT ServiceCharge

RoomCost ← Room * Nights
BreakfastCost ← Breakfast * Guests * Nights
ServiceChargeAmount ← RoomCost * ServiceCharge / 100

FinalCost ← RoomCost + BreakfastCost + ServiceChargeAmount

OUTPUT RoomCost
OUTPUT BreakfastCost
OUTPUT ServiceChargeAmount
OUTPUT FinalCost
Hard

3. 🛒 Online Shopping Checkout

An online store needs to calculate a customer's final bill.

The program receives:

  • Price of product
  • Quantity
  • Discount percentage
  • Delivery charge
  • Tax percentage

Write Cambridge pseudocode that:

  1. Inputs the product price.
  2. Inputs quantity.
  3. Inputs discount percentage.
  4. Inputs delivery charge.
  5. Inputs tax percentage.
  6. Calculates the subtotal.
  7. Calculates the discount.
  8. Calculates the price after discount.
  9. Calculates tax.
  10. Calculates the final cost.
  11. Outputs the final cost.

Formula

Subtotal = Price × Quantity

Discount = Subtotal × DiscountPercent / 100

AfterDiscount = Subtotal - Discount

Tax = AfterDiscount × TaxPercent / 100

FinalCost = AfterDiscount + Tax + Delivery

Example

Price = 1200
Quantity = 3
Discount = 10
Delivery = 150
Tax = 7
Subtotal = 3600 Discount = 360 AfterDiscount = 3240 Tax = 226.8 FinalCost = 3616.8
🚨 Important
Students must recognize that Tax depends on AfterDiscount. Therefore, the sequence matters.
Answer pseudocode
INPUT Price
INPUT Quantity
INPUT DiscountPercent
INPUT Delivery
INPUT TaxPercent

Subtotal ← Price * Quantity
Discount ← Subtotal * DiscountPercent / 100
AfterDiscount ← Subtotal - Discount
Tax ← AfterDiscount * TaxPercent / 100

FinalCost ← AfterDiscount + Tax + Delivery

OUTPUT FinalCost
Very Hard

4. 🎮 Game Tournament Score

A game records a player's performance in three rounds.

The program must:

  1. Input the player's name.
  2. Input Round 1 score.
  3. Input Round 2 score.
  4. Input Round 3 score.
  5. Input a bonus score.
  6. Calculate the total score.
  7. Calculate the average score before the bonus.
  8. Calculate the final score including the bonus.
  9. Output the player's name.
  10. Output the average.
  11. Output the final score.

Example

Round1 = 80
Round2 = 70
Round3 = 90
Bonus = 20
Total = 240 Average = 80 FinalScore = 260

🧠 Sequence Detective

Ask students: Why should Average be calculated before adding the bonus?

Model answer: If the bonus were added to Total before Average is calculated, the average would be inflated and would no longer represent the player's true round-by-round performance. Order changes the meaning of the result, not just the number of steps.

Answer pseudocode
INPUT PlayerName
INPUT Round1
INPUT Round2
INPUT Round3
INPUT Bonus

Total ← Round1 + Round2 + Round3
Average ← Total / 3
FinalScore ← Total + Bonus

OUTPUT PlayerName
OUTPUT Average
OUTPUT FinalScore

5. 🚗 Car Rental System — Expert Challenge

A car rental company calculates the cost of a rental.

The program inputs:

  • Daily rental price
  • Number of rental days
  • Insurance per day
  • Number of extra drivers
  • Extra driver fee per day
  • GPS rental per day
  • Tax percentage

The program must calculate:

  1. Basic rental cost.
  2. Insurance cost.
  3. Extra driver cost.
  4. GPS cost.
  5. Subtotal.
  6. Tax.
  7. Final rental cost.

Required formulas

RentalCost = DailyPrice × Days

InsuranceCost = Insurance × Days

DriverCost = ExtraDrivers × DriverFee × Days

GPSCost = GPS × Days

Subtotal = RentalCost + InsuranceCost + DriverCost + GPSCost

Tax = Subtotal × TaxPercent / 100

FinalCost = Subtotal + Tax

Example

DailyPrice = 1500
Days = 5
Insurance = 200
ExtraDrivers = 2
DriverFee = 150
GPS = 100
Tax = 7
RentalCost = 7500 InsuranceCost = 1000 DriverCost = 1500 GPSCost = 500 Subtotal = 10500 Tax = 735 FinalCost = 11235
Reminder for delivery: students should not be given the formulas initially — make them derive each calculation from the problem description, then check their working against this key.
Answer pseudocode
INPUT DailyPrice
INPUT Days
INPUT Insurance
INPUT ExtraDrivers
INPUT DriverFee
INPUT GPS
INPUT TaxPercent

RentalCost ← DailyPrice * Days
InsuranceCost ← Insurance * Days
DriverCost ← ExtraDrivers * DriverFee * Days
GPSCost ← GPS * Days

Subtotal ← RentalCost + InsuranceCost + DriverCost + GPSCost
Tax ← Subtotal * TaxPercent / 100
FinalCost ← Subtotal + Tax

OUTPUT RentalCost
OUTPUT InsuranceCost
OUTPUT DriverCost
OUTPUT GPSCost
OUTPUT Subtotal
OUTPUT Tax
OUTPUT FinalCost

🧠 Final Boss — Debug the Sequence

Broken program given to students:

INPUT DailyPrice
INPUT Days
INPUT TaxPercent

Tax ← Subtotal * TaxPercent / 100

INPUT Insurance
INPUT ExtraDrivers
INPUT DriverFee
INPUT GPS

FinalCost ← Subtotal + Tax

RentalCost ← DailyPrice * Days
InsuranceCost ← Insurance * Days
DriverCost ← ExtraDrivers * DriverFee * Days
GPSCost ← GPS * Days

Subtotal ← RentalCost + InsuranceCost + DriverCost + GPSCost

OUTPUT FinalCost

Student instructions

Do not simply rewrite it. Find the sequence errors and explain:

  1. Which variables are being used before they are calculated?
  2. Which calculation should happen first?
  3. Which calculation depends on Subtotal?
  4. Why can't Tax be calculated at the beginning?
  5. Rewrite the complete algorithm correctly.
Model answers (1–4)
  1. Subtotal is used in the Tax calculation before it has been given a value — at that point in the program it is undefined.
  2. RentalCost, InsuranceCost, DriverCost, and GPSCost should be calculated first, since Subtotal is their sum.
  3. Tax and FinalCost both depend on Subtotal. Tax needs it directly for the percentage calculation, and FinalCost needs it as the base to add Tax onto.
  4. Tax can't be calculated at the beginning because it is a percentage of Subtotal, and Subtotal itself depends on four other values (RentalCost, InsuranceCost, DriverCost, GPSCost) that haven't been input or calculated yet at that point.
Corrected algorithm (5)
INPUT DailyPrice
INPUT Days
INPUT TaxPercent
INPUT Insurance
INPUT ExtraDrivers
INPUT DriverFee
INPUT GPS

RentalCost ← DailyPrice * Days
InsuranceCost ← Insurance * Days
DriverCost ← ExtraDrivers * DriverFee * Days
GPSCost ← GPS * Days

Subtotal ← RentalCost + InsuranceCost + DriverCost + GPSCost

Tax ← Subtotal * TaxPercent / 100

FinalCost ← Subtotal + Tax

OUTPUT FinalCost
